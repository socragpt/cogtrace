# EXP-NNN: Short experiment title

- **Status:** Planned
- **Evidence level:** Fixture | Live engineering smoke | Frozen collection
- **Created:** YYYY-MM-DD
- **Run date:** Not run
- **Owners:** CogTrace contributors
- **Code revision:** Record exact commit at run time
- **Data classification:** Synthetic | Private raw CoT | Redacted public

## Question

State the narrow question this experiment can answer.

## Non-claims

State tempting conclusions this experiment cannot support.

## Prerequisites and approvals

List required gates, external resources, spending, credentials, and approvals.

## Frozen configuration

Record tasks and split, model and exact revision, server/runtime version,
hardware, treatments, prompts, sampling settings, seeds, monitor and validator
versions, output path, and analysis code.

## Procedure

Give the exact commands or link to a versioned runbook.

## Acceptance criteria

Define engineering success or preregistered research metrics before the run.

## Deviations

Record every departure from the frozen configuration. Write “None” only after
the run.

## Results

Separate observed counts and measurements from explanation.

## Interpretation

State what the result supports, what it does not support, and uncertainty.

## Artifacts

List immutable or access-controlled locations, checksums when useful, and the
retention or redaction status.

## Next decision

State which gate or experiment follows from the result.
